# Issue #28 – Nhập nhiều giao dịch giọng nói

**Thành viên:** Việt | Backend
**Phạm vi bàn giao / rà soát:**
- Rà soát xử lý câu nói chứa một hoặc nhiều giao dịch.
- Đối chiếu số tiền, ngày, danh mục và loại giao dịch.
- Kiểm tra dữ liệu nhập không rõ hoặc sai.

**Minh chứng cần đối chiếu:** Ví dụ câu nói giả lập và kết quả phân tích.
